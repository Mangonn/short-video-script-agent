# 04 AI 使用与个人贡献

## 我的工作

我明确了短视频脚本题的事实与时长边界：P01 只提供“支持字幕”这一事实；首稿超时必须压缩并重新估算；没有效果数据时不能编造“效率提升 80%”。我要求按统一规范交付代码、测试、实际输出和 Trace。

我审阅代码后，向 Codex 提出离线 Mock 文案过于单薄的问题，要求提升分镜可读性，同时保持真实模型记录与 Mock 流程验证的明确区别。我用参考实例和评审反馈核对了修订方向。

## AI 辅助范围与分工

我使用 Codex 完成需求细化、Python 实现、合成素材、规则、测试、示例生成和文档；DeepSeek 通过函数调用生成并修订真实脚本。Codex 负责具体代码修改、测试、真实模型运行和提交。程序工具独立核对时长与素材引用；Mock 不证明真实模型的创作效果。

## 验证与记录边界

Codex 在本地运行了 21 项测试、14 组离线示例和 7 组真实模型路径，结果见 03-evaluation.md 和 examples/。我提出事实约束、验收重点和评审后的修改意见。
